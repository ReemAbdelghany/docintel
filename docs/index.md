# Document Intelligence Service

Upload a PDF or an image of a contract or an invoice and get structured, verified data back, or a manual review task when the system cannot be confident.

- **Using the service:** start with the [tutorial](user-guide/tutorials/upload-your-first-document.md) and the [API reference](user-guide/reference/api.md).
- **Running and changing it:** see the [setup guide](developer-guide/setup.md) and the [architecture](developer-guide/architecture.md).
